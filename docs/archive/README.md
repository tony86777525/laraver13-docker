# Archive

This directory stores historical analysis, drafts, and retired reference material.

Files here are not active implementation specs. When archived content is still useful, move or summarize the relevant parts into:

- `docs/specs/` for feature behavior.
- `docs/architecture/` for technical structure.
- `docs/decisions/` for accepted decisions.

Do not implement directly from archived files unless the user explicitly asks for archival reconstruction or comparison.
